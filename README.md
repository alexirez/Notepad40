# Notepad40

A lightweight cross-platform notepad app built with .NET MAUI, focused on fast startup, responsive UI navigation, and a clean sticky-note inspired design.

## Features

- Fast note creation and editing
- Persistent local note storage
- Adjustable font sizing
- Cross-platform support with .NET MAUI
- Lightweight MVVM architecture

## Tech Stack

- C#
- .NET MAUI
- MVVM Pattern
- ObservableCollection + Data Binding

## Roadmap

- Sticky note inspired UI redesign
- Randomized note colors
- Improved note organization
- UI animations and polish
- Theme customization
